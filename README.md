# Flowlist · Todo List

一个无需构建工具、打开即用的响应式 Todo List 页面。

## 功能

- 新增、编辑、完成和删除任务
- 删除后可在 5 秒内撤销
- 按全部、今天、进行中、已完成筛选
- 支持任务搜索、分类、优先级和截止日期
- 自动计算完成进度和任务统计
- 深色 / 浅色模式
- 使用浏览器 `localStorage` 自动保存数据
- 移动端适配和键盘无障碍支持

## 使用

直接用浏览器打开 `index.html` 即可。也可以在项目目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 技术栈

原生 HTML、CSS 和 JavaScript，无第三方运行时依赖。
